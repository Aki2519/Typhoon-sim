| 字段 | 类型 | 含义 |
|---|---|---|
| `mode` | str | `"equirect"` / `"conic"` |

## 3. 核心机制详解

### 3.1 网格为什么能无损抠出来

`xrq-dolphin.png` 只有 **3022 种颜色**，前 5 色覆盖 **95.70%**：

| RGB | 像素数 | 占整图 | 角色 |
|---|---|---|---|
| `(0, 34, 68)` | 1 755 659 | **78.082%** | 海洋 |
| `(48, 112, 80)` | 353 603 | **15.726%** | 陆地 |
| `(62, 88, 114)` | 25 882 | 1.151% | 水印（叠海洋） |
| `(99, 147, 123)` | 9 751 | 0.434% | 水印（叠陆地） |
| **`(102, 204, 153)`** | **6 915** | **0.308%** | 网格 + 一档强度色 |

把 `(102,204,153)`（容差 ≤3）单独做成掩码，得到的是 **3418 px 的虚线经纬网，一条杂线都没有**（无陆地、无标记、无文字污染）。这是整个投影反推的基础 —— 它把"从图里提取结构"这件本来很难的事变成了**精确二值化**。生成过程见 §5 的第一条复现命令。

### 3.2 两路互相独立的几何事实，给出同一个 n

**事实一：经线是过同一点的直线束（圆锥投影的定义性质）。**

RANSAC 找到 8 条直线，然后**两两求交**：

```
交点中位数 = (918.1, -1768.5)
交点 x: min=918 max=918  std=0.0      ← 28 对，x 完全重合
交点 y: min=-1770 max=-1768  std=0.3
```

28 对交点、跨 1261 px 的经线，**x 标准差 0.0 px**。等距圆柱投影的经线是**平行**的（交点在无穷远），所以这一条就排除了"等距圆柱"。

8 条经线的倾角 `ang = 73.133, 77.619, 82.105, 86.591, 91.076, 95.562, 100.047, 104.531`，相邻差 **4.4855°**（极均匀）。按 `x@y=1200` 排序确认左→右对应 λ=120…190°E（含 180 与 190=170°W，与图上底部标注一致），取 `σ = 90° − ang`：

```
σ = n·(λ − λ0)   →   n = 0.448557,  λ0 = 152.3985°E
角残差 RMS = 0.000773°,  最大 = 0.001531°   ≈ 0.076 px @ ρ=2968px
```

**事实二：纬线是同心圆弧。**

以顶点为圆心，6 条纬线的半径：

| ρ (px) | 1878.017 | 2098.782 | 2309.810 | 2518.602 | 2731.560 | 2955.177 |
|---|---|---|---|---|---|---|
| 像素数 | 201 | 283 | 287 | 322 | 303 | 296 |
| **圆度残差 std** | 0.224 | 0.224 | 0.286 | **0.101** | 0.210 | 0.244 |

半径标准差 **0.10–0.29 px** —— 是**近乎完美的圆**。纬度归属由左边缘标注文字的 y 位置核对：`ρ=2955.115` 在 x=0 处 y=1040 对应图上的 `0°`，`ρ=2098.720` 对应 `40°N`，故 6 环 = **50/40/30/20/10/0°N**。

**两个来源的 n 相对差 1.59e-5**（修正顶点后）：经线角 0.448557 vs 纬线半径 0.448550。这不是"拟合出来的巧合" —— 它们来自图上**两组互相独立的几何量**（角度与半径）。

### 3.3 三族候选：Lambert 正形圆锥胜出 3 个数量级

同样 6 条纬线，自由参数最小二乘：

| 族 | 公式 | RMS 残差 | 最大残差 |
|---|---|---|---|
| **Lambert 正形圆锥** | `ρ = A·tan(π/4+φ/2)^(-n)` | **0.0032 px** | **0.0049 px** |
| 等距圆锥 | `ρ = A − B·φ` | 3.816 px | 4.890 px |
| Albers 等积 | `ρ = A·√(C − D·sinφ)` | 7.551 px | 9.736 px |

逐环残差（px）：

| lat | ρ 实测 | Lambert | 等距 | Albers |
|---|---|---|---|---|
| 50 | 1878.017 | 1878.018 | 1880.116 | 1881.895 |
| 40 | 2098.782 | 2098.779 | 2094.199 | 2089.883 |
| 30 | 2309.810 | 2309.815 | 2308.284 | 2307.508 |
| 20 | 2518.602 | 2518.605 | 2522.368 | 2526.537 |
| 10 | 2731.560 | 2731.557 | 2736.451 | 2740.772 |
| 0 | 2955.177 | 2955.180 | 2950.534 | 2945.442 |

Lambert 的残差（0.003 px）**远低于像素栅格**，等于"模型精确"。所以我早先一度担心的"纬线间距呈 U 形"是**有限差分放大噪声**的假象：相邻 ρ 相减（220.77/211.03/208.79/212.96/223.62）看似非单调，但绝对残差全部 ≤0.004 px。

### 3.3b 逐像素残差（与上面"参数级残差"是**两个口径**，别混用）

| 口径 | 定义 | 数值 |
|---|---|---|
| A. 半径律残差 | `A·t(φ_j)^(-n) − ρ_j`，6 条纬线 | RMS **0.0032 px**，max 0.0049 px |
| B. 角度律残差 | `n(λ_k−λ0) − σ_k`，8 条经线 | RMS **0.000773°** ≈ **0.076 px** @ρ=2968 |
| **C. 逐线像素残差（经线）** | 内点到拟合直线的垂距 RMS | **0.090–0.119 px**（8 条，内点 163–217） |
| **D. 逐弧像素残差（纬线）** | `ρ − ρ_j` 的标准差 | **0.101–0.286 px**（6 条，内点 201–322） |
| E. 顶点一致性 | 8 条经线到公共顶点的距离 | max **0.071 px** |

A/B 远小于 1 px，是因为它们只在**参数空间**里比较 6 个半径 / 8 个角度；C/D 才是像素级，量级 0.1–0.3 px，受限于**像素栅格与虚线渲染**（1 px 宽的抗锯齿虚线，其最亮像素本身就有 ±0.5 px 量化）。两者不矛盾，但**不能互相冒充**。

### 3.4 公式（可直接复现）

```
球面 Lambert 正形圆锥：中央经线 λ0、圆锥常数 n
    t(φ) = tan(π/4 + φ/2)
    ρ(φ) = ρ_k · ( t(φ) / t(φ_k) )^(-n)          ρ_k = 参考纬度 φ_k 处的半径
    σ(λ) = n · (λ − λ0)                          弧度；东侧 σ>0
    X = ρ·sin(σ)
    Y = ρ·cos(σ)                                 Y 向下为正（自圆锥顶点起算）
    像素 = (ox + scale·X,  oy + scale·Y)

本图（基准图原生像素尺度，scale=1）：
    n = 0.448550        λ0 = 152.3985°E
    ρ_k = 2955.1775 px  φ_k = 0°
    顶点 (ox, oy) = (918.0277, -1768.5631)
```

若要按标准纬线表达：`n = ln(cosφ1/cosφ2) / ln(tan(π/4+φ2/2)/tan(π/4+φ1/2))`。
**但本图不是"整度"标准纬线**：20/40 → n=0.5026、30/60 → n=0.7157、单切纬 φ=26.65° → n=0.4486。所以本模块以 **n 与 ρ_k 为第一性参数**，不硬凑标准纬线（见 §7 U1）。

| 0 | `(0, 250, 244)` | 1650 | 1770 |
| 1 | `(94, 186, 255)` | 6915 | 3957 |
| 2 | `(102, 204, 153)` | 2507 | 2608 |

| 4 | `(255, 231, 117)` | 3811 | 3014 |

**水印 = 白色 @ alpha 62**（这是解出来的，不是试出来的）。基准图里水印叠海洋得 `(62,88,114)`、叠陆地得 `(99,147,123)`，两者同时被下式精确复现：

```
白色×62/255 + 底色×193/255:
  海  0.243·255+0.757·0    = 62   ✓   0.243·255+0.757·34   = 88    ✓ (+0.3)
      0.243·255+0.757·68   = 114  ✓
  陆  0.243·255+0.757·48   = 98.3 ≈99 ✓  0.243·255+0.757·112 = 146.8 ≈147 ✓
```

一个 alpha 值同时解释 6 个通道，且与两种底色都吻合 ⇒ 这个解是唯一的。

### 3.6 陆地采样：按输出画布裁剪源图（本轮返工的重点）

**第一版错了两处**（都是实测抓出来的）：

1. **行序反了**：`simulator/env/model/land_cell.npz` 的 row 0 = 90°S，而 `map/land.png` 的 row 0 = 90°N。我用了同一套 `j=(lat+90)/dlat` 索引 ⇒ **陆地上下翻转**。
2. **经度口径混用**：`land.png` 是 0–360，我把反投影结果归一化到 −180..180 ⇒ 裁剪窗口 `[max(0,lon0), min(360,lon1)]` 退化成**整圈**，且 `fx = lon·ppd − x0` 在西侧变负被夹到 0 ⇒ **右半张图多出一大块假陆地**（陆地占比 27.3% vs 基准 14.7%）。

**现在**：`_canvas_window()` 用画布四条边各 48 点反投影求经纬度窗口（跨 0° 经线时返回 `None` 交给兜底掩码），`_land_window()` 只 `crop` 那一块（窗口 75°×48° ≈ 3.2 M px ≈ 13 MB float32），再**按投影逐像素双线性采样** —— 不是"拉伸图片"，因为圆锥下经纬度与画布像素不是仿射关系。二值掩码经双线性后天然得到 0..1 的**边缘覆盖率**，混色即得抗锯齿海岸线。

## 6. 观察到的问题 / 风险 / 不一致

### MAJOR-1｜顶点搜索的"集中度"度量有尺度污染（差点得出反面结论）

第一版用"经线像素在顶点处的角度直方图集中度"找顶点，结果 **cy = −100000（无穷远）得分最高** ⇒ 会得出"经线平行、是等距圆柱"的**相反结论**。原因是：cy→−∞ 时所有 θ 塌缩到 0 附近，直方图自然集中，随固定 bin 数的集中度指标被尺度带偏。改用 **RANSAC 直线束 + 两两求交**（几何上等价于"经线共点"）后，28 对交点 xσ=0.0 px。**教训：优化目标必须对要检验的假设尺度不变量。**

### MAJOR-2｜`map/land.png` 与 `land_cell.npz` 的行序相反

`land.png` 的 row 0 = 90°**N**（`y = (90-lat)*30`），`land_cell.npz` 的 row 0 = 90°**S**（`j=(lat+90)/dlat`）。我第一版对两者用同一套索引 ⇒ **陆地整体上下翻转**。实测表现：`(150E,20N)` 本应是海却取到陆。已在 `_sample_land_window`（`y=(90-lat)*ppd`）与兜底分支（`j=(lat+90)/dlat`）里分别写对，并在注释里点明这个差异。

### MAJOR-3｜经度口径混用 ⇒ 裁剪窗口退化成整圈

`inverse_arrays` 返回 0–360（与 `land.png` 一致），我却又归一化到 −180..180 去算窗口 ⇒ `lon0` 变负、`lon1` 可能到 360，`_land_window` 的 `[max(0,lon0−m), min(360,lon1+m)]` 变成整圈，`fx` 在西侧变负被夹到 0 ⇒ **右半张图多出一大块假陆地**（陆地占比 27.3% vs 基准 14.7%，纯陆像素 614 680 vs 353 603）。去掉归一化后降到 14.39%（−2.2%）。跨 0° 经线的情况现在显式返回 `None` 交给兜底掩码。

### MAJOR-4｜素材：第一份 `.dat` 是别的台风

Lead 最初给的 `202613 白海豚 Dolphin wp122026.dat` 内容为 `chunshu`、首点 209°E —— 与基准图（右端 190°E）不符。**判定依据是量出来的**：图内轨迹右端反解 190.54°E，而该文件首点 209°E。换成 `bwp122026.dat`（`XRQA`，首点 191.6°E）后端点吻合 0.02°。⇒ 别人给的素材要**用数据自己核一遍**。

### MINOR-1｜TV 的分母口径会让结论翻转

同一份渲染，**逐色精确匹配** TV = 0.0204、**最近邻归属** TV = 0.0296；而在我把水印补齐**之前**（几乎没水印）精确匹配口径只有 0.0052 —— 那个 0.0052 是**指标偏袒**（KEY 里没有水印色，水印缺席反而不扣分）。现在把水印色加进 KEY、并改用最近邻归属，0.0296 才是可比的数。

### MINOR-2｜水印的抗锯齿性格贡献了 TV 的 2.83%

本渲染的水印用 `smoothscale` 放大后再 `rotate`，α 分布比基准图更"两极"（核心更锐、边缘更少）。可优化点：直接按目标字号渲染文本（不 smoothscale），或对 α 做量化。未做，因为收益只在 0.02 量级且不改变视觉结论。

### MINOR-3｜兜底掩码与源图的小岛差异

0.5° 掩码丢掉了大量小岛礁，导致 A/B 对比里出现 max 344.9 px 的远距离改动像素（§5.5）。兜底只在裁剪失败（跨 0° 经线 / PIL 缺失）时启用，正常路径不受影响。

### MINOR-4｜`LAND_PPD_MAX` 是为了 A/B 才加的旋钮

`LAND_PPD_MAX > 0` 时把裁剪窗口降采样到该 px/° 再采样，仅用于"改前"复现与省内存。默认 0（= 用源图 30 px/°）。它是个调试口，不是正常路径。
