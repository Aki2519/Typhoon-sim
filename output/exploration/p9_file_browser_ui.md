### 6.4 DPI 缩放（125% / 150%）—— ⚠ **查不了，如实说明**

- **为什么查不了**：本机验收一律 headless（`SDL_VIDEODRIVER=dummy`），**dummy 驱动不经过 Windows DPI 虚拟化**；而纪律禁止开真窗口（`python main.py`）⇒ 无法在 125%/150% 下取帧。**这是环境限制，不是"没查"。**
- **已知事实**：`main.py:38` 调用了 `GetProcAddress(shcore/user32)` 设置 **DPI awareness**（进程级），因此 Windows 不会对窗口做位图拉伸 —— **不会出现"整体模糊"**。
- **推断（未实测）**：本对话框的布局/字号/间距**全部按物理像素硬编码**（`DIALOG_W/H`、`ROW_H=26`、`_TB_BTN_W=96`），**没有任何 DPI 缩放系数** ⇒ 150% 缩放下等效可用逻辑分辨率变小，**会更容易触发 K1/K12 这类"宽度不够"的问题**（如 2560 物理宽 @150% ≈ 1706 逻辑宽，仍在"工具条 1 行 OK"的 1600 之上，但余量变小）。
- **建议**：若要真正支持高 DPI，需要引入 dpi 系数（字体与几何同乘）或"最小窗口尺寸"守卫；这不属于本轮（UI 收尾）范围。
